# 재료비 관리 시스템 구축 - 5단계 로드맵 (조직 내부 계획 원본)

문서버전: v1.0 (2026-08-13, 사용자 제공 이미지 기준 정리)

> 목표일정은 내부 목표일로, 확정 마감이 아님. 본 BRD/PRD의 프로토타입은 이 로드맵의 PHASE 1을 검증하기 위한 선행 단계.

## 전체 목표

- BOM 기반 재료비 취합/관리 시스템 구축
- 재료비 Database화
- 개발단계별 실시간 재료비 조회
- AI 활용 제품군별 가격범위 확인
- 양산이후 약정인하/원자재 변동 추적관리

## PHASE 1 - 시스템 내 BOM 구성 및 재료비 입력 (목표일정 ~2026-08-31)

- 포함정보: E-BOM정보(LEVEL/품번/품명/제품사이즈/수량/C·O여부/재질·표면처리·규격/중량/비고), 필터링정보(제품군/하위품목/사양/REVISION), 소싱정보(생산지역/생산공장/MIP·LP·KD), 재료비정보(CURRENCY/단가/재료비), 물류정보(작업수량/포장비/운임/관세율), 차종정보(SOP/한율기준/원자재기준)
- 주요기능: BOM 엑셀 업로드(초기) → 추후 시스템 직접입력 / 입력권한 수정 / 권한분리(관리자·설계자) / 재료비 SUMMARY(KD·LP - 품목군 Sub total, 총재료비 Grand total) / 엑셀 업로드·다운로드
- 필요 Data(DB): NE2 BOM (양식통일 필요, 설계협조 필요)
- 목표: 각 담당자가 실시간으로 충돌없이 입력 가능한 시스템 구현

## PHASE 2 - 단계별 재료비 별도 관리 (목표일정 ~2026-09-31)

- 관리항목: 개발단계(입찰/PROTO/PILOT/양산)별 단일 재료비 관리(최종 Version 관리), 구간별 재료비 차액분석
- 주요기능: 재료비 확정/잠금(무분별한 수정 방지), 재료비 Version 관리
- 목표: 한 차종에 대한 각 시점별 재료비 관리, 사양변경에 따른 재료비 변동 추적관리

## PHASE 3 - 목표가 관리 (목표일정 ~2026-10-31)

- 재료비 인하항목 관리: C/O가격적용, 업체선정 Nego, LTA, 물량 Nego 등
- 주요기능: 품목별 목표가 입력기능 추가
- 목표: (PHASE2와 동일) 시점별 재료비 관리, 사양변경 변동 추적

## PHASE 4 - 약정인하/원자재 연동관리 (목표일정 ~2026-11-31)

- 관리항목: 품목별 약정인하 정보(총재료비 or 가공비), 소재/소재코드/시점별 단가, HMG 원소재 관리 Table
- 주요기능: 재료비 Click 시 변동이력 확인(총전대비 변동금액, 한 품목당 여러 소재 연동이력 확인)
- 목표: 단가변경 연간 효과금액(+/-) 관리, 연간 재료비 절감금액 관리를 통한 실적관리 연계, 원자재 품의 여부 추적관리

## PHASE 5 - 시점/차종별 재료비 비교 (목표일정 ~2026-12-31)

- 차이발생항목별 금액분리: 사양변경/원자재변동/환율변동/소싱변경/구매가인하/구매가인상/상각비변동/기타
- 주요기능: 서로 다른 BOM 자동매칭기능, 매핑오류 시 수동매칭 수정, BOM 매칭 후 차액에 대한 분석
- 필요 Data(DB): 차종별 BOM DB(엑셀)
- 목표: 각 시점별 재료비 변동 사유분석, 차종별 재료비 차이여부 분석
- 비고: BOM 자동매핑 기능 구현 가능여부 확인 필요
