## 이번에 반영된 기능

### BOM 비용 입력·계산

- 재료단가, 물류단가, 관세율, 금형비 입력 후 자동 저장/재계산.
- `Tab`으로 칸을 이동해도 행 전체를 다시 그리지 않도록 변경. 포커스가 끊기지 않음.
- 계산 결과만 비동기로 갱신: 총 재료비, 총 물류비(물류비+관세), 총비용.
- 수동 저장 버튼 유지. 저장 성공 시 버튼이 `Saved` 상태로 변경.
- 천 단위 쉼표가 포함된 숫자 입력을 계산 가능하도록 처리.
- 저장 후 `입력 완료/미입력` 상태 배지도 즉시 변경.

### 비용 정의

- 총 재료비 = 재료단가 × 수량 × 환율.
- 총 물류비 = 물류단가 × 수량 + 관세비.
- 총비용 = 총 재료비 + 총 물류비 (관세 중복 합산 방지).
- 국내 케이스 비용 = 총 재료비.
- 해외 케이스 비용 = 총 재료비 + 총 물류비.

### 화면 개선

- BOM 상단에 국가 케이스 탭 추가: 한국/미국/유럽.
- 현재 선택 국가를 탭 활성화 및 `Current: ...` 레이블로 표시.
- 품명에 BOM 레벨(L0~L6) 배지와 들여쓰기 표시.
- 대시보드에 차종·국가별 국내/해외 케이스 비용 비교 추가.

### 변경 이력

- `purchase_history` 테이블 추가.
- 단가/통화/관세/금형비 변경 시 이전 값, 새 값, 변경자, 변경 시각을 기록.
- 행별 이력 조회 API: `GET /bom/row/<part_no>/<row_num>/<country>/history`
- 아직 이력을 보여주거나 되돌리는 화면/버튼은 없음.
